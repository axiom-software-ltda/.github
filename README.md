## O que fazemos

A Axiom Software entrega software de alta qualidade para empresas que precisam de sistemas confiáveis. 
Do backend ao produto, aplicamos engenharia rigorosa e inteligência artificial onde faz diferença — sem ruído, sem atalhos.

| Área | Descrição |
|---|---|
| **Desenvolvimento de Software** | APIs, backends, automações e sistemas distribuídos construídos com atenção ao detalhe |
| **Inteligência Artificial** | Integração de LLMs, agentes autônomos e pipelines de dados para produtos reais |
| **Produtos Digitais** | Interfaces e aplicações de ponta a ponta, do design system à produção |

## Contribuindo

Todos os repositórios públicos da Axiom aceitam contribuições via pull request. Antes de abrir um PR:

1. Leia o `CONTRIBUTING.md` do repositório correspondente
2. Siga as convenções de código e commit do projeto
3. Abra uma issue descrevendo a mudança proposta antes de implementar
